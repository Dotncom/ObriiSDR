# Obrii SDR 9.0.7

## Готові зміни

- Виправлено оновлення локалізації поруч з EXE: `translations.json` синхронізується після збірки, тому актуальні українські підписи не перекриваються застарілою копією.
- Очищено назви кнопок без зайвих трикрапок, зокрема TX, FFT, Zero Span, Multi-SDR, станції FT8 та відкритого радіо.
- Уточнено компактні елементи керування передавачем і локалізовані підписи профілів шуму.
- Оновлено готовий локальний DMR/TX-шлях, не змінюючи стандартні приймальні бекенди.

## Склад

Windows Full містить програму, консольні інструменти, FPGA Lab, Analyzer, альтернативні прошивки Fobos та утиліту їх завантаження. Raspberry archive містить вихідний код і сценарії збирання.

Окремий експериментальний IPSC-проєкт у цей реліз не входить.
